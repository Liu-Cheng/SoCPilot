  \textbf{Deployment description}\par\smallskip
  We need a compact color-marker inspection node beside an industrial production line.
  A nearby production controller indicates when an item is positioned; the node captures an image,
  locates a colored marker, and reports its center coordinates and a validity flag.
  An operator adjusts the detection settings during commissioning.
  The camera, trigger wiring and controller communication connection have not been chosen.
  The node does not directly drive production actuators.
  \par\smallskip
  Keep the supplied processor and image storage unchanged.
  Inside the node, the processor must independently address the camera configuration, trigger status,
  inspection settings and result-status register banks.
  These low-volume control transactions need address decoding and register-target selection;
  they are not bulk frame transfers and must not be confused with the external controller link.
  Recommend I/O and internal control interconnect functions with endpoint assumptions.
  Do not invent bus widths, physical protocols, guaranteed response times or a requirement for a routed multi-tile network.
  \end{minipage}}
