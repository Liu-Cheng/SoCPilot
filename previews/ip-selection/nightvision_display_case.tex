  \textbf{Deployment description}\par\smallskip
  We want a self-contained low-light viewing terminal for an operator working without a continuous remote connection.
  The terminal receives paired images from two imaging modules, enhances and fuses them locally, and presents the resulting view on a nearby display.
  The two image streams must be associated with the correct capture pair rather than mixed across unrelated frames.
  The operator should be able to change viewing settings using a small local control panel.
  Recommend external image-acquisition, display, and local-control functions and identify what must be confirmed about the endpoints.
  Assume the processing and memory platform already exists.
  \end{minipage}}
