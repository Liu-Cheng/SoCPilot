\section{Conclusion}
Application-driven SoC customization requires coordinating interdependent software and hardware decisions across a complex toolchain, demanding substantial expertise and manual effort. To address this challenge, we propose SoCPilot, an end-to-end agentic framework that combines LLM-based planning, code generation, and feedback reasoning with application profiling and quantitative design optimization. Prototype-based measurements on five applications show a geometric mean end-to-end speedup of 2.47$\times$ over matched CPU-only execution. Using the same DeepSeek model, SoCPilot generates designs that reach FPGA execution for all five applications, whereas the general-purpose agent completes the evaluated HSCO-Bench generation flow for none. SoCPilot's advantage lies in structuring the design process around domain-specific stages, explicit intermediate representations, and tool-derived feedback, which constrain code generation and guide design decisions and revisions. These results support combining LLM reasoning with specialized design methods and tools to automate application-specific SoC customization.
